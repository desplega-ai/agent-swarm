### Runtime pools (#2045, `RUNTIME_POOLS`)

`RUNTIME_POOLS_ENABLED` defaults off, so `Heartbeat.cfg` sets `RUNTIME_POOLS = FALSE`; run with `RUNTIME_POOLS=TRUE` to check the pool paths. A pool agent without a runtime is modeled as a worker that is not alive.
