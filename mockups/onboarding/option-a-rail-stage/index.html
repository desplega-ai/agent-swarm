    Step 6 of 6

    Run your first task

    A worker is the machine that does the work. Start one, then hand it a small task and watch it run.

    06

    Start a worker

    Run this on any machine with Docker. It registers itself with the API.

    docker run -d --name swarm-worker \
  -e MCP_BASE_URL=http://localhost:3013 \
  -e AGENT_SWARM_API_KEY=sk-swarm-…•••• \
  -e HARNESS_PROVIDER=claude \
  ghcr.io/desplega-ai/agent-swarm-worker:latest

    The URL, key and provider above match what you verified in steps 1 and 3.
