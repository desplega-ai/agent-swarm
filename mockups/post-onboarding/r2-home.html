Home: two columns of widgets, timeline below

Every section is a widget with one anatomy: icon, title, a count or status, one action on the right, then the body. The left column is what to act on, the right column is what to set up and come back to. The columns share one width, one top edge and one 16px gap, and every widget is as tall as its content.

  • Rows, not cards in cards. Needs you, In progress, the checklist and Favorites are lists with hairline rules. Only Approve uses the amber fill.
  • In progress groups by use case, with the star on favorites, so the swarm reads as a set of jobs, not a flat task list.
  • The timeline keeps the real look: agent lanes, an hourly axis, status-colored bars and the amber now-line. Zoom sits in the empty gutter corner, so the header matches the other widgets.

The desktop states need a window wider than 760px. The phone frames follow.
