Use-case group: the Overview tab

A use case is a Sessions group with a schedule or with files under its key. When you open it, the tab strip gets two tabs: a pinned Overview first, then the session list. The list tab does not change. The Overview answers three questions at a glance: when does it run next, what did it make, and what do I tell the Lead.

  • Left column, steer and browse: the schedules (per-row switch, Run now on hover, read-only template) and the files under the group key, newest first.
  • Right column, read and reply: the selected file in a preview, then Ask the Lead with its last two replies. The composer can attach the file you are reading.
  • Scale: the schedule list caps at 400px and scrolls inside itself. From 8 schedules up it gets a search field. The header row stays on top.
  • No Overview for a group with no schedule and no files. It appears when the group gets its first schedule or its first file.

The desktop states need a window wider than 760px. The phone frames follow.

1Overview tab, 3 schedules, report preview open

The default view of a use case. Click a file to preview it, a Template link to read the task, the caret next to Run now to run another schedule, or the tabs to switch.

2Overview tab, 50 schedules, search for "pricing"

A big swarm. The search matches names, agents and cadences, and the list keeps its sticky header and its scrollbar gutter. One template is open, and the row under the pointer shows Run now in place of its next run. Type in the field to filter.

3List tab active, next to the pinned Overview

The session list as it is today: title row, filter bar, grid and pager. The pinned Overview tab sits first, with a pin in place of the close button. It closes when its list tab closes.

4A plain thread group: no Overview tab

ui-e2e has no schedule and no files under its key, so it opens one tab, as today. Nothing in the list chrome hints at an empty Overview.

Phone

A phone has no tab strip. The group screen shows the two tabs as underline tabs under its top bar. The Overview is one column: next run, outputs with the newest report open, schedules, then the Lead. The composer stays at the bottom.
