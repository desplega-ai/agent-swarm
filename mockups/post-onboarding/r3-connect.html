Connect: three pages, one sidebar group

Channels, Tools and AI providers are three pages, each opened from its own sidebar entry. Each page has a title and nothing under it. Only Tools has tabs, because it holds four kinds of connection.

  • Routes. /integrations/channels, /integrations/tools (each tab is a sub-path, for example /tools/oauth-apps) and /integrations/ai-providers. The old URLs redirect.
  • Tools tabs. Tools, Script connections, OAuth apps, MCP servers. Providers stay as cards. Everything else is a list in the DataGrid look. Under the tabs, one toolbar: search on the left, the add action as an icon button on the right.
  • One search per page at most. Channels and AI providers show five or six cards, so they get no search. The ⌘K search in the top bar still finds every provider.
  • Advanced is a quiet link at the end of the tab strip. It opens Settings › Advanced, which now holds Connection playground and Raw fetch credentials.
  • Same card anatomy as round 2: mark, name, one line of purpose, a status chip, and a footer with the detail and one outline action.

The desktop states need a window wider than 760px. The phone frames follow.

Channels

Opened from Connect › Channels in the sidebar, or from the checklist item "Connect a chat channel".

Tools › Tools

The default tab. Connected tools sort first. The search filters the open tab. Advanced sits at the far end of the tab strip in the muted text color, and opens Settings › Advanced.

Tools › OAuth apps

The client apps that accounts sign in through. One row per app: provider, status, how many scopes it asks for, the accounts connected through it, and the tools that use it. The add action is the icon button at the right end of the toolbar.

Tools › MCP servers

Extra tools that agents call. One row per server: transport, status, how many tools it exposes and how many agents have it installed.

AI providers

As round 2: one card per provider with its keys, a health chip that sums up the keys, and an inline Add key row. The warning dot in the sidebar comes from the rate-limited Anthropic key.

Phone

The page name moves into the top bar. The Tools tabs scroll sideways, with Advanced at the end of the strip. Cards stack and list rows drop to name and status.
