Connect, round 4: the breadcrumb names the page, one top row, AI providers from the code

Desktop pages have no title. The breadcrumb in the top bar names the page. Every Connect page starts with one row: search on the left, the primary action on the right. AI providers shows only what the code supports today, with the real config keys and the real setup steps.

  • Top row. Channels: Search channels and Connect a channel. AI providers: Search providers and keys and Add key. Tools: the search sits in the tab row, after the tabs, then the Add action, then Advanced.
  • Phone. The top bar shows a compact page title. On Tools, the tabs scroll and the search and add buttons stay pinned at the right.
  • AI providers. One section per configured family: status, How to get a key, the pooled keys, and an Add row. A key row shows its plan, the cost today and over 7 days, the 5 h and 7 d windows, and when an agent last used it.
  • Key actions. The row menu has Rename, Set plan, Clear rate limit and Remove. Remove asks for a confirm. Click a key to open its drawer.
  • Not yet supported. A dashed tag marks each thing that the API or the dashboard cannot do yet. The list of sources is at the end of the page.

The desktop states need a window wider than 760px. The phone frames follow.

(1) AI providers: overview

Three configured families: Claude subscription, Codex subscription and OpenRouter. The token taras-backup hit its 5 h window, so its menu is open on Clear rate limit. How to get a token is open on the Claude section. The others are compact below, then the providers that this page cannot add yet.

(2) AI providers: key detail drawer

Click a key row (or its name) to open the drawer. It shows why the key is limited and when it comes back, usage with daily bars, plan and windows, the rate-limit record, the agents that draw from the pool, and Remove. Esc or the scrim closes it.

(2b) Remove, with a confirm

Opened from Remove in the row menu or the drawer (AlertDialog). The text says what happens to running tasks and that the swarm cannot revoke the token at the vendor.

(3) Tools › Tools: search in the tab row

One row holds the tabs, the search for the open tab, the Add action and Advanced. On the Tools tab, Add opens a menu: Script connection, OAuth app, MCP server. On the other tabs it adds that tab's item.

(3b) Tools › OAuth apps

Same row. The search placeholder and the Add label follow the tab.

(4) Channels: the top row

The round-3 cards, under the new top row. Connect a channel opens the same choice as the cards, for people who look for the button first.

Phone: (1) and (3)

The top bar shows a compact title. Key rows drop to two lines with a 44px menu target. On Tools, search and add stay pinned at the right of the scrolling tabs.

Where the AI providers data comes from

Paths are relative to the repo root. Read in the worktree on 2026-11-04.

  • Families and config keys. The llm entries in apps/ui/src/lib/integrations-catalog.ts (Anthropic, OpenRouter, OpenAI, Codex ChatGPT OAuth, Amazon Bedrock, Claude Managed Agents, Memory, Transcription) and the registry in packages/model-catalog/src/openai-compatible-providers.ts (NaN, Helmcode, Vercel AI Gateway).
  • Key row fields. ApiKeyStatus in apps/ui/src/api/types.ts: name, plan, planSource, status, rateLimitedUntil, lastUsedAt, lastRateLimitAt, rateLimitCount, rateLimitWindows. Window names come from WINDOW_LABELS in apps/ui/src/pages/api-keys/page.tsx.
  • Actions. Rename, Set plan and Clear rate limit: use-api-keys.ts (PATCH /api/keys/name, PATCH /api/keys/plan, POST /api/keys/clear-rate-limit). Add and Remove: use-pool-keys.ts (/api/config/pool-keys). Codex accounts: codex_oauth_<n> slots.
  • Costs. All time and task count: KeyCostSummary from GET /api/keys/costs. Today and 7 days: byCredential from GET /api/usage/summary?groupBy=both&startDate=…. For subscriptions this is the API value of the runs, as in subscriptions-card.tsx.
  • Plans and prices. src/utils/subscription-plans.ts (Claude Pro, Max 5x, Max 20x, Team; ChatGPT Go, Plus, Pro 5x, Pro 20x, Business).
  • How-to text. apps/ui/src/pages/setup/steps/ai/claude-card.tsx and codex-card.tsx, the key URLs in step-memory.tsx, and the docs guides/provider-auth/codex-oauth.mdx and model-gateways.mdx.
  • Not yet supported. Daily bars for one key (the usage summary has no key filter). Which agent used which key (no per-key agent split). A dated list of limits (the API keeps the count and the last one). 5 h and 7 d bars for Codex (only Claude Code reports window events). The eight env-only providers: no catalog entry, so this page cannot add or pool them.
