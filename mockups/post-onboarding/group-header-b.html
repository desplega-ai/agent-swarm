IdeaOne 48px strip: star and name, next run, Run now, output count, chat. The list starts right below, so the group still reads as a session list first. A click on the strip opens the full schedule, outputs and chat box.
Trade-offCheapest in height and the same strip works on phone. But the latest report and the template are one click away, and the chat box hides behind an icon, so "talk to the use case" is less obvious.

Desktop states are hidden on narrow screens. Widen the window to see them.
