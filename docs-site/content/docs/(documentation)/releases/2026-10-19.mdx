Seven releases shipped this week — v1.171.1, v1.172.0, v1.173.0, then 2.0.0 through 2.3.0 — across 146 merged commits. The core got smaller while the surface got wider: 2.0 takes out three subsystems, and chat channels, model gateways and a real script runtime go in.

## Breaking Changes

> **Self-hosters: act before the next deploy.** 2.0.0 changes the worker image, the entrypoint and the MCP tool surface.

### Agent Swarm 2.0 removes PM2, the service registry and artifacts

[#2147](https://github.com/desplega-ai/agent-swarm/pull/2147) deletes PM2 process management, the service registry (services page, `use-services` hooks, service MCP tools) and the artifacts feature. The worker image and entrypoint no longer start PM2, and `ecosystem.config.cjs` is gone. Long-running work now lives in pages, apps and scripts.

- Replace PM2-supervised processes with scripts or scheduled tasks.
- Publish UIs as pages or apps instead of artifacts.
- Remove service and artifact tool calls from prompts, skills and scripts.
- Rebuild from the new `Dockerfile.worker`; see the [deployment guide](/docs/guides/deployment).

### Config rows opt in to env export

[#2156](https://github.com/desplega-ai/agent-swarm/pull/2156) adds a per-row `exportToEnv` flag, so a config value reaches agent env only when its row says so. Audit every value your agents read from `process.env` and check it is marked for export.

### Heartbeat hygiene is on by default

[#2226](https://github.com/desplega-ai/agent-swarm/pull/2226) ships heartbeat hygiene and the built-in Jev checklist gate ([#2182](https://github.com/desplega-ai/agent-swarm/pull/2182)) enabled. If you relied on the previous heartbeat cadence, review the gate before deploying a large fleet on it.

## Highlights

### One channel for four chat platforms

[#2125](https://github.com/desplega-ai/agent-swarm/pull/2125) adds the Chat SDK channel: one adapter for Telegram, Slack, Teams and Discord, configured from the Integrations page, with Helm and compose examples. The same agent answers in a Telegram group and a Teams channel without a second integration. Docs: [chat-sdk](/docs/integrations/chat-sdk).

### Scripts get a guarded runtime with real I/O

Two changes turn scripts from pure compute into a safe working surface. [#2114](https://github.com/desplega-ai/agent-swarm/pull/2114) puts scripts behind a QuickJS egress guard, so a script reaches only the hosts you allow and credentials are injected at egress instead of entering script memory. [#2198](https://github.com/desplega-ai/agent-swarm/pull/2198) and [#2139](https://github.com/desplega-ai/agent-swarm/pull/2139) add `ctx.fs`, `ctx.sh` and SQL script connections: read and write agent-fs, run shell over it, and query registered SQL databases. Docs: [scripts runtime](/docs/guides/scripts-runtime).

### More models, routed and profiled

- [#2176](https://github.com/desplega-ai/agent-swarm/pull/2176) adds the Vercel AI Gateway (Token Pass): the full chat model catalog behind one fixed endpoint.
- [#2172](https://github.com/desplega-ai/agent-swarm/pull/2172) adds NaN and Helmcode as OpenAI-compatible providers on pi and opencode, and [#2189](https://github.com/desplega-ai/agent-swarm/pull/2189) routes registry models such as `nan/*` to their own endpoint from raw-llm workflow nodes.
- [#2163](https://github.com/desplega-ai/agent-swarm/pull/2163) resolves model profiles at claim time: you name a profile, and the concrete model and effort are chosen when a worker claims the task. [#2158](https://github.com/desplega-ai/agent-swarm/pull/2158) records the effort a task actually ran at, so cost reporting and re-runs stop drifting.

### Azure DevOps Boards

[#2119](https://github.com/desplega-ai/agent-swarm/pull/2119) adds work-item triggers and tracker sync. [#2169](https://github.com/desplega-ai/agent-swarm/pull/2169) adds opt-in state transitions and workflow triggers on work-item events. Docs: [azure-devops](/docs/integrations/azure-devops).
