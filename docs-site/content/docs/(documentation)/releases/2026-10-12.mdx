Seven releases shipped this week — v1.164.0 through v1.169.0 — across 168 merged commits. The swarm got safer to trust and easier to adopt: secrets can no longer leak through any write path, workflows compose, scripts run lighter, and a single command stands up a self-hosted swarm. A note on scope: 19 commits landed on main after the v1.169.0 tag and are in no release yet; each is marked "on main, ships in the next release" below.

## Highlights

### Secrets are scrubbed everywhere they could land

A credential that reaches an agent never lands in a log, event, memory, task, workflow step or outbound message. A central secret registry learns every credential the API knows, survives restarts, and catches encoded copies of known values ([#1918](https://github.com/desplega-ai/agent-swarm/pull/1918)). A vendored gitleaks rule set — pinned to v8.30.1 and verified by sha256, replacing 19 hand-written token shapes — covers vendor credentials ([#1922](https://github.com/desplega-ai/agent-swarm/pull/1922)). Write-time scrubbing now covers event payloads, script runs, workflow runs and steps, memory, messages, approvals, schedules and task text ([#1924](https://github.com/desplega-ai/agent-swarm/pull/1924), [#1925](https://github.com/desplega-ai/agent-swarm/pull/1925), [#1926](https://github.com/desplega-ai/agent-swarm/pull/1926), [#1927](https://github.com/desplega-ai/agent-swarm/pull/1927)), plus HTTP error bodies, telemetry and Slack/WhatsApp egress ([#1911](https://github.com/desplega-ai/agent-swarm/pull/1911), [#1914](https://github.com/desplega-ai/agent-swarm/pull/1914), [#1919](https://github.com/desplega-ai/agent-swarm/pull/1919)). `db-query` refuses credential tables outright ([#1915](https://github.com/desplega-ai/agent-swarm/pull/1915)), gitleaks runs in merge-gate ([#1910](https://github.com/desplega-ai/agent-swarm/pull/1910)), and a versioned retro-sweep scrubbed existing rows ([#1917](https://github.com/desplega-ai/agent-swarm/pull/1917)).

Two mechanisms keep it true: a canary sweep plants three shape-less canaries — one per way the API learns a secret — and verifies none survive in any table or stdout ([#1928](https://github.com/desplega-ai/agent-swarm/pull/1928)), and the merge gate fails when a TEXT column is not classified scrubbed, exempt or pending ([#1923](https://github.com/desplega-ai/agent-swarm/pull/1923)).

### Workflows now compose

A sub-workflow node lets a parent workflow start a child with explicit inputs, wait for it, and branch on its outcome ([#2030](https://github.com/desplega-ai/agent-swarm/pull/2030)). Re-executed steps reconnect to the existing child instead of spawning a second one.

### QuickJS script executor (opt-in)

`SCRIPT_EXECUTOR=quickjs` runs scripts in a WASM worker pool instead of a subprocess per run ([#1951](https://github.com/desplega-ai/agent-swarm/pull/1951)). The pool size is configurable ([#2037](https://github.com/desplega-ai/agent-swarm/pull/2037)) and the executor is selectable from the dashboard ([#2004](https://github.com/desplega-ai/agent-swarm/pull/2004)). Opt-in: the default subprocess executor is unchanged.

### Eight more ways to run agents

Native Cursor and Amp harnesses landed in v1.164.0 ([#1882](https://github.com/desplega-ai/agent-swarm/pull/1882), [#1883](https://github.com/desplega-ai/agent-swarm/pull/1883)), plus a Grok CLI harness that runs on an API key ([#1959](https://github.com/desplega-ai/agent-swarm/pull/1959)). ACP targets for GitHub Copilot CLI ([#1957](https://github.com/desplega-ai/agent-swarm/pull/1957)) and Gemini CLI ([#1956](https://github.com/desplega-ai/agent-swarm/pull/1956)) are live now; Qwen, Kiro and Goose presets are on main and ship in the next release ([#2067](https://github.com/desplega-ai/agent-swarm/pull/2067)) — Kiro needs a paid `KIRO_API_KEY`.

### One command to self-host

A `curl | bash` installer checks Docker and Compose, installs Bun, onboards you, waits for `/health` and prints the `/setup` link; `--tunnel` is optional ([#2064](https://github.com/desplega-ai/agent-swarm/pull/2064), on main, ships in the next release). Workers wait for credentials instead of failing when none are present yet. The dashboard also ships as a standalone nginx image ([#1943](https://github.com/desplega-ai/agent-swarm/pull/1943)).

## Improvements

- **Workflows and automation** — OpenAI and Cloudflare providers for `system-one-decision` nodes ([#1945](https://github.com/desplega-ai/agent-swarm/pull/1945)). An optional heartbeat gate script can skip quiet checklist ticks, in shadow mode by default ([#2033](https://github.com/desplega-ai/agent-swarm/pull/2033)), and the Lead boot-triage task is skipped on a clean boot ([#1973](https://github.com/desplega-ai/agent-swarm/pull/1973)). Scheduled script runs get a `script_runs` row ([#2021](https://github.com/desplega-ai/agent-swarm/pull/2021)); script connections can be hard-deleted ([#2020](https://github.com/desplega-ai/agent-swarm/pull/2020)); a script can send a task to its own agent ([#2019](https://github.com/desplega-ai/agent-swarm/pull/2019)); a slack-reply-gate extension ships as a catalog template ([#2023](https://github.com/desplega-ai/agent-swarm/pull/2023)). Extensions bridge approval, budget, email, Kapso and code-host events as `post.*` events ([#1878](https://github.com/desplega-ai/agent-swarm/pull/1878)), and approvals take their responder from the credential and enforce the approvers policy ([#1854](https://github.com/desplega-ai/agent-swarm/pull/1854)).
- **Access and MCP** — One-click Connect to ChatGPT via single-use connector codes: 10-minute validity, hash-only storage ([#1903](https://github.com/desplega-ai/agent-swarm/pull/1903)). `SWARM_ENABLED_TOOLS` sets an exact per-agent tool allowlist; unset keeps today's surface ([#1989](https://github.com/desplega-ai/agent-swarm/pull/1989)). The `/connect` confirm step is inline instead of a dialog ([#1944](https://github.com/desplega-ai/agent-swarm/pull/1944)), OpenRouter requests are attributed to Agent Swarm ([#1995](https://github.com/desplega-ai/agent-swarm/pull/1995), [#1996](https://github.com/desplega-ai/agent-swarm/pull/1996)), and tool results get a per-channel budget, spill shape summaries and paged `kv-get` views ([#1949](https://github.com/desplega-ai/agent-swarm/pull/1949)).
- **Slack, pages and dashboard** — Durable Slack inbound receipts with explicit dispatch outcomes ([#1606](https://github.com/desplega-ai/agent-swarm/pull/1606)). An in-page feedback overlay sends element comments to the lead ([#2039](https://github.com/desplega-ai/agent-swarm/pull/2039)). The task detail page got a full overhaul on desktop and mobile ([#1881](https://github.com/desplega-ai/agent-swarm/pull/1881)), and page sessions get a guest principal ([#1955](https://github.com/desplega-ai/agent-swarm/pull/1955)). Skill usage and adoption surface in the dashboard ([#2068](https://github.com/desplega-ai/agent-swarm/pull/2068), on main, ships in the next release).
- **Evals and quality** — Nightly and weekly eval schedules with regression checks and a Slack summary ([#1768](https://github.com/desplega-ai/agent-swarm/pull/1768)), a read-only publish-bundle endpoint for the weekly benchmark publish ([#2046](https://github.com/desplega-ai/agent-swarm/pull/2046)), and nightly canary caps sized from measured cost ([#2041](https://github.com/desplega-ai/agent-swarm/pull/2041)). CI is faster and stricter: tsgo typechecks and a lighter merge-gate ([#1920](https://github.com/desplega-ai/agent-swarm/pull/1920)), test durations and flakes tracked per run ([#1986](https://github.com/desplega-ai/agent-swarm/pull/1986)), faster slow tests ([#2065](https://github.com/desplega-ai/agent-swarm/pull/2065)), vendored anti-slop Oxlint rules in CI ([#2038](https://github.com/desplega-ai/agent-swarm/pull/2038)), and a show-me PR template with review map, risk and swarm provenance ([#1937](https://github.com/desplega-ai/agent-swarm/pull/1937)).

## Migration Notes

- `db-query` now denies credential tables ([#1915](https://github.com/desplega-ai/agent-swarm/pull/1915)). Scripts that read them must use connections or credential bindings instead.
- With the new installer (on main, next release), `onboard --yes` no longer fails without a model credential — workers park in credential-wait until `/setup` supplies one.
- The QuickJS executor and `SWARM_ENABLED_TOOLS` are opt-in; defaults are unchanged.
