The week ran from v2.8.0 to v2.9.0 on 219 commits: 41 features, 58 fixes and 21 docs in the audit window. The through-line: the swarm now prices its own automation, so "does the fleet pay for itself?" answers from your own data. Two changes need a config edit.

## Highlights

### See what the fleet saves

[#2779](https://github.com/desplega-ai/agent-swarm/pull/2779) adds a fleet savings page at `/usage/savings`: what your scripts, schedules and workflows did, priced as what agent sessions would have cost instead. An agent would have spent a session cost at the run's tier, scaled by a failure-and-retry multiplier plus a lead review charge. Only deterministic glue is substituted; agent-task nodes keep their actual cost.

Savings come at four tiers (`smol`, `regular`, `smart`, `ultra`) as a band, not a point estimate. Constants were calibrated on 2026-11-05 against `claude-opus-5-5` costs, and the curve recalibrates from your own sessions ([#2770](https://github.com/desplega-ai/agent-swarm/pull/2770)).

- A workflow shows its saving in the header, a Savings tab and a daily chart ([#2768](https://github.com/desplega-ai/agent-swarm/pull/2768)); scripts and schedules show theirs on the page, rail and list ([#2776](https://github.com/desplega-ai/agent-swarm/pull/2776), [#2777](https://github.com/desplega-ai/agent-swarm/pull/2777)).
- A daily rollup backs a **Saved (30d)** column, and workflow totals break into components ([#2772](https://github.com/desplega-ai/agent-swarm/pull/2772), [#2780](https://github.com/desplega-ai/agent-swarm/pull/2780)).
- The fleet summary answers in a handful of statements, not a scan per row ([#2809](https://github.com/desplega-ai/agent-swarm/pull/2809)). Docs: [Savings API](/docs/api-reference/savings).

### Quota meters and provider limits on Usage

Usage now shows what is left before a provider throttles you: quota meters ([#2890](https://github.com/desplega-ai/agent-swarm/pull/2890)) beside current limits and observed window usage ([#2870](https://github.com/desplega-ai/agent-swarm/pull/2870)). Home gained savings, dismissible failures and a new top bar ([#2866](https://github.com/desplega-ai/agent-swarm/pull/2866)).

### Cards instead of walls of text

A task result can carry a json-render UI spec, so tables and charts render as a card, not a markdown dump ([#2876](https://github.com/desplega-ai/agent-swarm/pull/2876)). Cards also post to Slack and Chat SDK ([#2844](https://github.com/desplega-ai/agent-swarm/pull/2844)); prompts steer small chat tables into one ([#2860](https://github.com/desplega-ai/agent-swarm/pull/2860)).

### Apps that run a session, not just a query

`SessionThread` renders a live session inside an app, and an `app.action` step can start one ([#2760](https://github.com/desplega-ai/agent-swarm/pull/2760), [#2889](https://github.com/desplega-ai/agent-swarm/pull/2889)). `PageFrame` brings a `Chart`, a Metric sparkline and a sidebar shell ([#2884](https://github.com/desplega-ai/agent-swarm/pull/2884), [#2769](https://github.com/desplega-ai/agent-swarm/pull/2769)), and a catalog batch ships with approval, agent-fs files, a split drawer and a dialog ([#2810](https://github.com/desplega-ai/agent-swarm/pull/2810)). Docs: [Apps](/docs/apps/concepts).

### Onboarding: Work, Connect, Build

[#2734](https://github.com/desplega-ai/agent-swarm/pull/2734) is the week's largest change at 421 files: setup is three named groups, Work, Connect and Build, with in-app files, use-case groups and a Home page that shows what the swarm is doing. Docs: [Getting started](/docs/getting-started).

### Approvals answered where they are asked

A session's approval is answered in the dashboard, in place ([#2851](https://github.com/desplega-ai/agent-swarm/pull/2851)). The Slack card flips to resolved where it was posted and names the responder ([#2840](https://github.com/desplega-ai/agent-swarm/pull/2840), [#2847](https://github.com/desplega-ai/agent-swarm/pull/2847)); pending approvals sort above live activity ([#2864](https://github.com/desplega-ai/agent-swarm/pull/2864)). Docs: [HITL gates](/docs/playbooks/patterns/hitl-gates).

## Breaking Changes

No API removals, but two behavior changes:

- **context-mode is gone from the worker image and every harness adapter** ([#2812](https://github.com/desplega-ai/agent-swarm/pull/2812)). `CONTEXT_MODE_DISABLED` and `CONTEXT_MODE_EXTERNAL_MCP_NUDGE_EVERY` are now ignored. **Action:** drop both variables, and install the plugin in your own image if you need it.
- **Starting Linear or Jira OAuth now requires admin auth** ([#2756](https://github.com/desplega-ai/agent-swarm/pull/2756)). A non-admin start is refused. **Action:** have an admin start the tracker OAuth flow.
