250 commits landed from v2.12.0 to v2.13.2. The through-line is a shared workspace: agents and people edit the same spreadsheets and diagrams, waiting tasks are woken by the outside world instead of polling it, and every harness reports built-in tool calls to one hook surface. Six changes need an operator action, all under [Breaking Changes](#breaking-changes).

## Highlights

### Sheets and boards the swarm and your team edit together

[#3014](https://github.com/desplega-ai/agent-swarm/pull/3014) adds a sheet object: a spreadsheet with live formulas that lives on your drive and opens in the dashboard. The formula engine runs in a worker of its own, so a workbook recomputes on every write without blocking the API. [#3013](https://github.com/desplega-ai/agent-swarm/pull/3013) adds boards over Excalidraw element JSON: shapes, text, and arrows that bind at both ends. Both are files first, and a call returns a link a person can open and edit.

```ts
export default async function (args, ctx) {
  const { object, link } = await ctx.sheets.create({
    path: "shared/q4-planning/tracker.sheet.json",
    title: "Q4 tracker",
    tabs: [
      {
        name: "Tasks",
        rows: [
          ["Task", "Hours", "Cost"],
          ["Design", 3, "=B2*80"],
          ["Build", 5, "=B3*80"],
        ],
      },
    ],
  });
  await ctx.sheets.appendRows({
    id: object.id,
    tab: "Tasks",
    rows: [["Total", "=SUM(B2:B3)", "=SUM(C2:C3)"]],
  });
  return { id: object.id, link };
}
```

- **xlsx in and out.** `sheet-import-xlsx` keeps tabs, values, formulas, number formats, column widths and merges; `sheet-export-xlsx` writes them back, reporting what the other format cannot hold ([#3038](https://github.com/desplega-ai/agent-swarm/pull/3038)).
- **Open it where the work already is.** HTTP routes read and save objects ([#3074](https://github.com/desplega-ai/agent-swarm/pull/3074)). An app shows a live, editable object with `ObjectEmbed` ([#3093](https://github.com/desplega-ai/agent-swarm/pull/3093)), a page embeds one with `<swarm-object>` ([#3122](https://github.com/desplega-ai/agent-swarm/pull/3122)), and a Markdown file renders `<SwarmSheet id="..." />` or `<SwarmBoard id="..." />` in place ([#3116](https://github.com/desplega-ai/agent-swarm/pull/3116)).
- **Pointers stay current.** agent-fs `file.changed` webhooks keep the object pointer on each file in sync ([#3037](https://github.com/desplega-ai/agent-swarm/pull/3037)), and `object-reindex` takes a prefix and a `dryRun` and names the fix when a sheet lost its id ([#3076](https://github.com/desplega-ai/agent-swarm/pull/3076)).
- **Agents get the habit.** A seeded `boards-and-sheets` skill teaches the choice: a sheet for data that changes, a board for a diagram someone will move, a Markdown table for something read once ([#3073](https://github.com/desplega-ai/agent-swarm/pull/3073)).

Docs: [scripts runtime](/docs/guides/scripts-runtime), [objects API](/docs/api-reference/objects).

### Deferred tasks wake on an external event

A deferral no longer has to poll. `defer-task` takes a `wakeOn` event beside its usual deadline ([#3087](https://github.com/desplega-ai/agent-swarm/pull/3087)):

```json
{
  "wakeOn": { "event": "vcs.pr.merged", "source": "github", "match": { "repo": "owner/name", "number": 123 } },
  "note": "Run the post-merge checks on the merge commit."
}
```

GitHub's `pull_request.closed` webhook only names a candidate: the server reads the PR and wakes you when it actually merged. A closed-unmerged PR does not wake you; the ceiling does. The call is refused when the event already happened, the integration is off, or you hold 20 pending waits. GitHub is the only provider so far.

Docs: [scheduling](/docs/concepts/scheduling).

### One tool-hook surface on four harnesses

Claude Code, Codex, pi and opencode report each built-in call to `POST /api/tool-hooks` before it runs ([#3090](https://github.com/desplega-ai/agent-swarm/pull/3090)). `pre.tool.call` can block a call with a reason the model reads, or rewrite its arguments, and the rewrite lands on every harness, a Codex `apply_patch` patch included ([#3177](https://github.com/desplega-ai/agent-swarm/pull/3177), on main after v2.13.2). The shims fail open: an API slower than two seconds lets the call through, and workers send nothing until an extension lists `native` in its `toolSources`.

Docs: [extensions](/docs/guides/extensions).

### Rocket.Chat joins Chat SDK

A self-hosted team can talk to the swarm where it already works ([#3120](https://github.com/desplega-ai/agent-swarm/pull/3120)): an adapter over the Rocket.Chat REST API and one Outgoing WebHook, no new npm dependency. The instance URL lives in `CHAT_SDK_API_URL_OVERRIDES`, not the adapter config, so a saved token cannot reach another host. `userName` is required because the REST API cannot report the bot's own name ([#3128](https://github.com/desplega-ai/agent-swarm/pull/3128) moves Chat SDK to 4.45.0).

Docs: [Chat SDK](/docs/integrations/chat-sdk).

### Code mode as the requesting user over MCP

An MCP client that runs code mode now does so with the caller's identity and permissions, not a shared service account ([#3144](https://github.com/desplega-ai/agent-swarm/pull/3144)).

### Sessions that pick up where you left off

Star sessions, star and hide groups, and open a Done Slack session from the list, where a channel or DM counts as one session ([#3051](https://github.com/desplega-ai/agent-swarm/pull/3051), [#3061](https://github.com/desplega-ai/agent-swarm/pull/3061)). The composer keeps drafts and gains `@` and `/` mentions ([#3047](https://github.com/desplega-ai/agent-swarm/pull/3047)); follow-ups mirror into the Slack thread ([#3048](https://github.com/desplega-ai/agent-swarm/pull/3048)); Claude pre-tool updates render as progress lines ([#3011](https://github.com/desplega-ai/agent-swarm/pull/3011)).

## Improvements

- **Runner** reaps the git worktrees agents leave behind ([#3118](https://github.com/desplega-ai/agent-swarm/pull/3118), [#3121](https://github.com/desplega-ai/agent-swarm/pull/3121)).
- **Repos** carry a per-repo merge policy record, so the rule follows the repository ([#3088](https://github.com/desplega-ai/agent-swarm/pull/3088)). Docs: [repo merge policy](/docs/guides/repo-merge-policy).
- **Workflows** accept an `hmac-sha1` webhook verification format ([#3092](https://github.com/desplega-ai/agent-swarm/pull/3092)).

- **Providers** prefer a subscription over an API key for OpenAI ([#3100](https://github.com/desplega-ai/agent-swarm/pull/3100)), run a pi agent on a ChatGPT subscription ([#3085](https://github.com/desplega-ai/agent-swarm/pull/3085)), propose the newest catalog models in setup, and list OpenCode Go ([#3039](https://github.com/desplega-ai/agent-swarm/pull/3039)).
- **Performance**: one warm native harness per script spec ([#3147](https://github.com/desplega-ai/agent-swarm/pull/3147)), read-only idle polls that take the write lock only to claim ([#3089](https://github.com/desplega-ai/agent-swarm/pull/3089)), memory search off the event loop ([#3081](https://github.com/desplega-ai/agent-swarm/pull/3081), [#3097](https://github.com/desplega-ai/agent-swarm/pull/3097)), app rows scanned in key windows ([#3079](https://github.com/desplega-ai/agent-swarm/pull/3079)).
- **Tooling**: a `get-task-details` response fitted to a size budget ([#3135](https://github.com/desplega-ai/agent-swarm/pull/3135)), primitives for spec-only app widgets ([#3117](https://github.com/desplega-ai/agent-swarm/pull/3117)), Fireworks and Bedrock resolved for internal titling and summaries ([#3095](https://github.com/desplega-ai/agent-swarm/pull/3095), on main after v2.13.2).
- **People and files**: dismiss an unmapped identity and hide `[bot]` logins ([#3075](https://github.com/desplega-ai/agent-swarm/pull/3075)); stale comments drop out of the Files send tray ([#3082](https://github.com/desplega-ai/agent-swarm/pull/3082)).

## Breaking Changes

Six behavior changes for operators. Each tightens a permission or a trust boundary; none removes an API.

- **Env and secret workflow inputs require `config.read.secrets`** ([#3046](https://github.com/desplega-ai/agent-swarm/pull/3046), [#3049](https://github.com/desplega-ai/agent-swarm/pull/3049)). Grant it to agents that run workflows rendering env or secret inputs, param-rendered ones included.
- **Repo-scoped script connections require `config.read.secrets`** ([#3137](https://github.com/desplega-ai/agent-swarm/pull/3137)). Grant it to agents that invoke them.
- **Only the creator or a lead changes what a schedule runs** ([#3134](https://github.com/desplega-ai/agent-swarm/pull/3134)). Route schedule target edits through the creator or a lead.
- **Unknown Slack teams fail closed** ([#3103](https://github.com/desplega-ai/agent-swarm/pull/3103), [#3094](https://github.com/desplega-ai/agent-swarm/pull/3094), [#3091](https://github.com/desplega-ai/agent-swarm/pull/3091)). A sender from another Slack team gets unknown trust: no email linking, no Work Object access.
- **Drive invites and script actions are narrowed** ([#3098](https://github.com/desplega-ai/agent-swarm/pull/3098), [#3104](https://github.com/desplega-ai/agent-swarm/pull/3104)). Issue shared-drive invites as the operator key or a user; only a script's owner can wire an owned global script as an app action.
- **`EVALS_API_KEY` is required when serving with `NODE_ENV=production`** ([#3062](https://github.com/desplega-ai/agent-swarm/pull/3062)). Set it before you upgrade a production deployment.
